# Real Estate Price Prediction — MLOps

Estimer le prix d'un bien immobilier à partir de ses caractéristiques et de son environnement local, pour aider à mieux comprendre les différences de prix.

Le projet prévoit de combiner les transactions DVF (Demandes de valeurs foncières) avec la BPE (Base permanente des équipements), en s'appuyant sur un référentiel des communes.

L'objectif Data/ML/MLOps est de construire une préparation des données reproductible, puis un modèle prédictif et les pratiques nécessaires à son cycle de vie.

Ce dépôt est une reconstruction indépendante d'un projet réalisé dans le cadre d'une formation Data Science Full Stack.

**État : work in progress.** Seul le squelette de la phase Data Engineering est présent.
