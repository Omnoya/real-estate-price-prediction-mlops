# Données locales

Les données complètes ne sont pas versionnées. Les futurs téléchargements et résultats de traitement seront conservés localement dans `raw/`, `interim/` et `processed/`, dossiers exclus de Git.

Les sources, versions et modalités d'acquisition seront documentées dans `docs/data_sources.md` après vérification. Aucune donnée ni aucun modèle du projet historique n'est copié.

De petites fixtures pourront être versionnées dans `tests/fixtures/` pour les tests.
